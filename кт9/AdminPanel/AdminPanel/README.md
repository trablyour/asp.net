### Задания

1. Создайте проект ASP.Net Core (MVC или Razor Pages).
2. Настройте Identity Framework для аутентификации пользователей.
3. Создайте роли администратора и обычного пользователя.
4. Настройте политики авторизации для доступа к админ-панели.
5. Создайте основной шаблон админ-панели с навигацией по разделам: пользователи, настройки, отчеты.
6. Реализуйте функциональность для просмотра, добавления, редактирования и удаления пользователей.
7. Разработайте формы для добавления и редактирования пользователей.
